# Token Drop Manager

i was thinking about an airdrop tool for the wax blockchain.  A user could select a tokencontract or token to airdrop, the amount, then another token or token contract to airdrop to. it would automatically load a holder list of that token with by default all holders selected. A user could press 'airdrop' with the relevant fields filled and the airdrop would occur. Accounts could be excluded from the drop by the dropper deselecting them in the list. A user could also set an airdrop for a later time. Things such as ram and cpu costs also take into consideration
